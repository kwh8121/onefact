# Claude Code CLI 프로젝트 하네스 운영

> 적용: 프로젝트 루트의 Claude Code 지침·설정 · 기준일: 2026-10-16

공통 규칙은 [README.md](README.md), 설치·검토·되돌리기는 [INSTALL.md](INSTALL.md)를 따른다. CLI 바이너리와 계정 인증은 사용자 환경의 사전 조건이다. 이 문서의 설치 대상은 프로젝트 파일이다.

## 1. 범위와 파일별 책임

| 범위 | 경로 | 책임 |
| --- | --- | --- |
| 프로젝트·필수 | `CLAUDE.md` | 시작 지침과 공통 규칙의 위치 |
| 프로젝트·필수 | `.claude/settings.json` | 팀 공통 실행·권한 설정 |
| 프로젝트·선택 | `.claude/rules/` | 필요한 경우에만 분리하는 영역별 규칙 |
| 프로젝트·선택 | `.claude/skills/<name>/SKILL.md` | 프로젝트의 반복 업무 |
| 개인·프로젝트별 | `.claude/settings.local.json` | 기존 개인 예외 설정. 공용 설치 대상으로 사용하지 않음 |
| 사용자 | `~/.claude/settings.json`, 전역 지침·인증 | 기존 상태 유지. 프로젝트 설치 대상으로 사용하지 않음 |

필수는 이 하네스의 도입 기준이다. 기존 프로젝트 파일은 내용을 검토해 병합한다. `settings.local.json`은 프로젝트 안에 있지만 개인 설정이므로 팀 공용 설정과 구분한다. 새로 만들지 않으며 기존 파일은 보존하고 Git 제외 여부·실효 설정 영향을 확인한다. 사용자·관리자 설정도 함께 적용될 수 있다. [A2]

## 2. 프로젝트 진입 지침

프로젝트 루트 `CLAUDE.md`에 다음을 병합한다. 기존 파일을 통째로 덮어쓰지 않는다.

```markdown
# 프로젝트 실행 지침

- 작업 시작 시 루트 README.md의 공통 운영 규칙과 README-Claude.md를 읽고 적용한다.
- 이번 작업의 요구사항·완료 조건과 관련 코드만 확인한다.
- 실제 검증 명령과 실행 위치는 이 프로젝트의 스크립트·CI·개발 가이드에서 확인한다.
- 프로젝트 경로와 적용 설정의 출처를 확인하고 사용자 기본값과 구분한다.
- 최소 변경 후 필요한 검사를 실행하고 결과·미검증 범위를 보고한다.
- 승인 경계와 작업 기록은 README.md를 따른다.
- 기존 사용자 변경을 보존하고 범위 밖 수정은 하지 않는다.
```

이 구성에서는 `CLAUDE.md`를 명시적인 진입점으로 사용한다. `AGENTS.md`가 대신 로딩된다고 가정하지 않는다. README의 단순 링크는 본문 자동 포함 지시가 아니므로 실제 읽기 지시를 둔다. 사용자 전역 지침도 함께 적용될 수 있어 `/memory`에서 출처를 확인한다. [A1]

## 3. 프로젝트 설정

Claude Code를 선택하면 `.claude/settings.json`을 준비하고 [설치 가이드](INSTALL.md)의 최소 권한 설정을 병합한다. 권한 모드의 값은 설치 가이드를 정본으로 사용한다. 기존 정책이 다르면 충돌과 변경 영향을 검토한다.

`~/.claude/settings.json` 또는 `.claude/settings.local.json`을 수정해 공용 설정을 대신하지 않는다. 프로젝트 설정이 개인 예외·상위 정책·명령행 옵션에 영향을 받는지 확인한다. 프로젝트 파일만으로 인증·외부 접근·전역 MCP·Hook이 격리되지는 않는다. [A2]

## 4. 프로젝트 검토와 일상 운영

1. 프로젝트 루트에서 새 `claude` 세션을 시작한다.
2. `/memory`로 지침, `/status`로 프로젝트 경로와 설정 출처, `/permissions`로 실효 권한을 확인한다. 화면에서 확인할 수 없는 항목은 미검증으로 남긴다.
3. 프로젝트의 요구사항·검증 명령을 확인하고 작은 가역적 작업으로 지침 준수 → 검사 → 자체 검토 → 작업일지 흐름을 검증한다.
4. 지침·설정 변경 후 새 세션에서 다시 확인한다. `claude --version`, 로그인 상태, `claude doctor`는 사용자 환경의 진단이며 프로젝트 설치 완료 증거를 대신하지 않는다.

자동 메모리는 보조 정보다. 현재 프로젝트의 이슈·코드·문서가 우선한다. 필요한 Skill은 프로젝트 경로에 둔다. 사용자 `~/.claude/skills/`의 기존 Skill은 사용자 범위로 구분한다. MCP·Hook 등 확장은 별도 범위 검토 후 도입하며, 사용자 전역 설치를 이 프로젝트 설치에 포함시키지 않는다. [A3]
