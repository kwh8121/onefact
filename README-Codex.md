# Codex CLI 프로젝트 하네스 운영

> 적용: 프로젝트 루트의 Codex 지침·설정 · 기준일: 2026-10-16

공통 규칙은 [README.md](README.md), 설치·검토·되돌리기는 [INSTALL.md](INSTALL.md)를 따른다. CLI 바이너리와 계정 인증은 사용자 환경의 사전 조건이다. 이 문서의 설치 대상은 프로젝트 파일이다.

## 1. 범위와 파일별 책임

| 범위 | 경로 | 책임 |
| --- | --- | --- |
| 프로젝트·필수 | `AGENTS.md` | 시작 지침과 공통 규칙의 위치 |
| 프로젝트·필수 | `.codex/config.toml` | 이 프로젝트의 실행·승인 설정 |
| 프로젝트·선택 | 하위 `AGENTS.md` | 해당 디렉터리의 예외 규칙 |
| 프로젝트·선택 | `.agents/skills/<name>/SKILL.md` | 프로젝트의 반복 업무 |
| 사용자 | `~/.codex/config.toml`, 전역 지침·인증 | 기존 상태 유지. 프로젝트 설치 대상으로 사용하지 않음 |

필수는 이 하네스의 도입 기준이다. 기존 프로젝트 파일은 내용을 검토해 병합하고 개인 설정은 복사하지 않는다. 사용자·관리자 설정과 명령행 옵션도 영향을 줄 수 있으므로 프로젝트 파일의 존재와 실제 적용을 구분한다. 프로젝트 설정은 신뢰 상태의 영향을 받는다. [C2]

## 2. 프로젝트 진입 지침

프로젝트 루트 `AGENTS.md`에 다음을 병합한다. 기존 파일 전체를 덮어쓰거나 별도 수정 금지 지시를 무시하지 않는다.

```markdown
# 프로젝트 실행 지침

- 작업 시작 시 루트 README.md의 공통 운영 규칙과 README-Codex.md를 읽고 적용한다.
- 이번 작업의 요구사항·완료 조건과 관련 코드만 확인한다.
- 실제 검증 명령과 실행 위치는 이 프로젝트의 스크립트·CI·개발 가이드에서 확인한다.
- 프로젝트 경로와 적용 설정의 출처를 확인하고 사용자 기본값과 구분한다.
- 최소 변경 후 필요한 검사를 실행하고 결과·미검증 범위를 보고한다.
- 승인 경계와 작업 기록은 README.md를 따른다.
- 기존 사용자 변경을 보존하고 범위 밖 수정은 하지 않는다.
```

README 링크만으로 본문이 자동 포함되지는 않으므로 읽기 지시를 둔다. Codex는 전역 지침과 프로젝트 경로의 지침을 조합하며, 같은 디렉터리의 `AGENTS.override.md`는 일반 `AGENTS.md`보다 먼저 선택된다. 하위 규칙이 적용되는 경로도 확인한다. [C1]

## 3. 프로젝트 설정

Codex를 선택하면 `.codex/config.toml`을 준비하고 [설치 가이드](INSTALL.md)의 최소 설정을 병합한다. 승인 정책·샌드박스 값은 설치 가이드를 정본으로 사용한다. 기존 프로젝트 정책이 다르면 충돌과 변경 영향을 검토한다.

이 파일 대신 `~/.codex/config.toml`을 수정하지 않는다. 파일이 읽기 전용이거나 상위 정책 때문에 적용되지 않으면 원인을 기록하고 프로젝트 설치를 미완료로 표시한다. 프로젝트 설정만으로 인증·네트워크·외부 서비스·전역 확장 기능이 격리되지는 않는다. [C2]

## 4. 프로젝트 검토와 일상 운영

1. 프로젝트 루트에서 새 `codex` 세션을 시작한다.
2. 적용 지침, 현재 경로, 브랜치, 기존 변경과 실제 검증 명령을 확인한다.
3. `/status`, `/permissions`와 설정 관련 화면에서 실효 설정을 확인한다. 확인 가능한 설정 출처를 기록하고 확인 불가능한 항목은 미검증으로 남긴다.
4. 작은 가역적 작업으로 프로젝트 지침 준수 → 관련 검사 → 자체 검토 → 작업일지 흐름을 검증한다.
5. 지침·설정 변경 후 새 세션에서 다시 확인한다. 파일 생성이나 버전·로그인 확인만으로 완료를 판정하지 않는다.

필요한 Skill은 프로젝트 경로에 둔다. 사용자 전역 Skill과 프로젝트 `.agents/skills/`의 Skill은 범위를 구분한다. MCP·Hook 등 확장은 별도 범위 검토 후 도입하며, 사용자 전역 설치를 이 프로젝트 설치에 포함시키지 않는다. [C3]
